## 1. エグゼクティブサマリー

### コンセプト

ドイツ・黒い森（Schwarzwald）をモチーフにしたおとぎの国を舞台に、ゆめかわいいビジュアルとほのかな闇が同居するデッキ構築ローグライク。Slay the Spireの洗練されたデッキ構築メカニクスに、忘却前夜のようなVN（ビジュアルノベル）的物語体験を融合する。

### ジャンル・プレイモード

- **ジャンル:** デッキ構築ローグライク
- **メインモード:** ソロプレイ
- **対人:** オマケ要素（詳細未定）

### ユニークセリングポイント

1. **仲間カードシステム** — 出会ったキャラがカードとなり、感情値によって効果が変化する
2. **四属性の世界観** — 菓子・薔薇・人形・樹海。見た目ではなく「魂の出身地」で属性が決まる
3. **三層VN統合** — ランをまたぐ永続的な物語体験。かわいい表層の下に隠された闇が徐々に明かされる
4. **ゆめかわ×闇の二面性** — 7割の甘さと3割の闇。同じエフェクト素材が腐食・溶解に変化する演出

### 参考タイトル

| タイトル | 参照要素 |
|---------|---------|
| Slay the Spire | デッキ構築・マップ構造・エネルギー制戦闘 |
| 忘却前夜 | VN統合・ラン間の物語継続・フレーバーテキスト演出 |

## 3. 四属性システムとカードサンプル

### 設計思想

属性は「キャラの見た目」ではなく「その魂がどの世界に属するか」で決まる。
同じ幽霊・骨人形でも出身地が違えば別属性になる。
各属性のオーラカラーで即座に識別可能。

### 錬金術カラーとの対応

| 属性 | 錬金術色 | カラーコード | オーラ表現 |
|------|---------|------------|----------|
| 菓子 | 金（Gold） | バニラ金 `#F8E8A0` | 琥珀色に煌めく粒子 |
| 薔薇 | 赤（Crimson） | コーラル赤 `#F87878` | 深紅の花弁が散る |
| 人形 | 白（Bone White） | ミルクピンク `#F8D4E8` | 骨白の陶器光沢 |
| 樹海 | 黒（Schwarz） | スカイミント `#B4E8F8` | 漆黒に深緑が滲む |

## 4. 仲間カードシステム

### 概要

旅で出会ったキャラクターが「仲間カード」としてプレイヤーに加わる。
仲間カードは通常のデッキカードとは別枠で管理され、固有の呪文カードセットを持つ。

### 仲間カードの構成

```
┌──────────────────────────────┐
│  仲間カード                    │
│  ┌────────────────────────┐  │
│  │ キャラ名               │  │
│  │ 属性アイコン ＋ オーラ   │  │
│  │ ピクセルアートの立ち絵   │  │
│  ├────────────────────────┤  │
│  │ 感情値ゲージ ♡♡♡♡♡♡♡♡  │  │
│  ├────────────────────────┤  │
│  │ パッシブ効果            │  │
│  │ （感情値により変化）     │  │
│  ├────────────────────────┤  │
│  │ 紐付き呪文カード一覧    │  │
│  │ （2〜4枚）             │  │
│  ├────────────────────────┤  │
│  │ フレーバーテキスト       │  │
│  │ （感情値で内容が変化）   │  │
│  └────────────────────────┘  │
└──────────────────────────────┘
```

### 仲間スロット

- **同時所持上限:** 3体（推奨案。[→ 11章 未決定事項 #1](#未決定1)）
- 4体目を迎える場合、既存の仲間1体と「別れ」が発生する
- 別れ時には専用フレーバーテキストが表示される

### 仲間カードの獲得条件

| 獲得方法 | 詳細 |
|---------|------|
| 対話イベントノード | 会話の選択肢で条件を満たすと仲間化 |
| 戦闘後 | 特定の敵を倒した後に仲間化（感情値は低い状態でスタート） |
| 隠し部屋 | 沈黙選択で解放した部屋に出現するレアキャラ |

### 仲間カードの「破壊」

- 戦闘中、仲間カードが紐付く呪文カードを使用して仲間のHPが0になると「破壊」が発生
- 破壊時、別れのフレーバーテキストが1〜2文で表示される
- 破壊された仲間は紐付き呪文カードごとデッキから消滅する
- 破壊されても感情値は永続記憶に保存され、次ランでの再会時に参照される

### 紐付き呪文カード

- 仲間1体につき2〜4枚の固有呪文カードが紐付く
- これらのカードは仲間獲得時にデッキに加わり、仲間を失うと消滅する
- 感情値の段階によって呪文カードの効果がアップグレードされる

## 5. 感情値システム

### 数値設計

| 項目 | 値 |
|------|-----|
| 最小値 | 0 |
| 最大値 | 100 |
| 初期値（対話から獲得） | 20 |
| 初期値（戦闘から獲得） | 10 |
| 初期値（隠し部屋から獲得） | 30 |

### 感情値の段階

| 段階 | 範囲 | 状態名 | 効果 |
|------|------|--------|------|
| 1 | 0〜19 | 警戒 | パッシブ効果なし。紐付き呪文カードのコスト+1 |
| 2 | 20〜39 | 同行 | パッシブ効果なし。紐付き呪文カードは通常コスト |
| 3 | 40〜59 | 信頼 | パッシブ効果が発動。紐付き呪文カードの効果量+20% |
| 4 | 60〜79 | 絆 | パッシブ効果が強化。紐付き呪文カードに追加効果 |
| 5 | 80〜100 | 真心 | パッシブ効果が最大。真のフレーバーテキスト解禁。紐付き呪文カードが最終形態 |

### 感情値の変動要因

| 行動 | 変動量 | 備考 |
|------|--------|------|
| 対話で好意的選択 | +3〜+5 | キャラの属性に合った選択で増加 |
| 対話で沈黙 | +1〜+2 | 安全だが上昇量は低い |
| 対話で嘘をつく | +5〜+8 | 短期利得は大きいが、バレた場合-15 |
| 戦闘で仲間の呪文を使用 | +1 | 1戦闘あたり上限3 |
| 仲間を「盾」として使った場合 | -3 | 仲間のHPを消費する行為 |
| 仲間を破壊 | 0（固定） | 以降の上昇に永続ペナルティ（再会時の上限-10） |
| ラン間の減衰 | -5/ラン | 再会しない場合のみ |

### 永続記憶

- 感情値はランをまたいで保存される
- 再会した仲間は前回の感情値を引き継ぐ（減衰適用後）
- 会話履歴も保存され、2回目以降の出会いでは専用のセリフが発生する
- 破壊された仲間との再会では特別なセリフが用意される

## 6. マップ・進行構造

### マップ基本設計

Slay the Spire型の分岐路マップ。下から上に進行し、各ノードを選んで進む。

```
                    【ボス】
                   ／    ＼
                 ◆        ○
               ／  ＼    ／
             ●      ◇  ◆
           ／  ＼  ／  ／
         ○    ●  △  ●
        ／＼  ／    ＼
      ◇    ●      ○
       ＼  ／ ＼  ／
        ●    ◇
         ＼ ／
         【開始】

  ● = 戦闘  ◇ = 対話イベント  ○ = 商店
  △ = 休憩所  ◆ = 隠し部屋（条件付き）
```

### ノード種別

| ノード | アイコン | 出現率 | 内容 |
|--------|---------|--------|------|
| 戦闘 | ● | 45% | 通常戦闘。勝利でカード報酬 |
| 対話イベント | ◇ | 20% | VN形式の会話・選択。仲間獲得の可能性あり |
| 商店 | ○ | 10% | カード購入・削除・仲間アイテム |
| 休憩所 | △ | 10% | HP回復 or カード強化の二択 |
| 隠し部屋 | ◆ | 10% | 直前の対話イベントで「沈黙」を選んだ場合のみ開放 |
| エリートバトル | ★ | 5% | 強敵。高報酬＋レリック |

### 層構造

| 層 | テーマ | ノード数 | ボス |
|----|--------|---------|------|
| 第1層 | 森の入口（樹海色強め） | 12〜15 | 未定 |
| 第2層 | お菓子の街道（菓子色強め） | 14〜17 | 未定 |
| 第3層 | 時計塔の宮廷（薔薇＋人形） | 16〜19 | 未定 |
| 最終層 | 森の最奥 | 10〜12 | 真のボス |

| 項目 | 値 |
|------|-----|
| 初期エネルギー | 3/ターン |
| 初期手札枚数 | 5枚/ターン |
| 初期HP | 70（推奨案。[→ 11章 未決定事項 #2](#未決定2)） |
| ブロックのリセット | ターン開始時に消滅 |

### 仲間カードの戦闘配置

- 仲間カードは専用スロット（最大3枠）に配置される
- 仲間はパッシブ効果を毎ターン発動する
- 仲間の紐付き呪文カードはデッキに混ぜて引く
- 仲間にもHPがあり、0になると「破壊」される

### 属性相性システム（3案）

#### 案A：四すくみ型（推奨）

```
    菓子
   ↗    ↘
 樹海 ←→ 薔薇
   ↘    ↗
    人形
```

| 攻撃側 → 防御側 | 倍率 |
|----------------|------|
| 菓子 → 人形 | 1.5倍（甘さで動きを封じる） |
| 人形 → 薔薇 | 1.5倍（偽物が誓いを嘲笑う） |
| 薔薇 → 樹海 | 1.5倍（騎士の意志が森を切り拓く） |
| 樹海 → 菓子 | 1.5倍（森が甘い家を飲み込む） |
| 逆方向 | 0.75倍 |
| 同属性 | 1.0倍 |

**推奨理由:** わかりやすく、各属性に明確な役割が生まれる。デッキ構築の判断基準が明瞭。

#### 案B：二極対立型

| 対立 | 関係 |
|------|------|
| 菓子 ↔ 樹海 | 相互に1.5倍（甘さと闇の対立） |
| 薔薇 ↔ 人形 | 相互に1.5倍（本物と偽物の対立） |
| 同軸以外 | 1.0倍 |

**利点:** シンプル。覚えやすい。
**欠点:** 属性の戦略的深みが薄い。

#### 案C：共鳴型（相性なし＋シナジー）

- 属性間に有利不利はなし
- 代わりに、同属性カードを連続で使うと「共鳴ボーナス」が発生
  - 2連続：効果量+10%
  - 3連続：効果量+25%
  - 4連続：効果量+50%＋特殊エフェクト
- 異属性の混成デッキには別途「調和ボーナス」（4属性全てを1ターンに使用で全体バフ）

**利点:** デッキ構築の自由度が高い。属性をまたぐ戦略が有効。
**欠点:** 属性の個性が薄れる可能性がある。相性知識が不要なのでマンネリ化のリスク。

|------|------|----------|
| 甘縛 | 行動順-1/スタック | 菓子属性 |
| 眩暈 | 次の攻撃のダメージ-25% | 薔薇属性 |

## 8. VN三層システム

### 層1：仲間カードシステム（最優先実装）

**実装優先度：★★★（最高）**

ゲームプレイの根幹。戦闘とVNを繋ぐ中核システム。

| 要素 | 仕様 |
|------|------|
| 仲間カード | 固有の呪文カードセット（2〜4枚）を紐付けて管理 |
| 感情値 | 0〜100。段階ごとにカード効果・フレーバーテキストが変化 |
| 破壊時演出 | 別れのフレーバーテキスト表示（1〜2文） |
| 永続記憶 | ランをまたいで感情値・会話履歴を保持 |
| 再会システム | 同じ仲間と再会時、前回の関係を踏まえた会話が発生 |

### 層2：選択システム

**実装優先度：★★☆**

対話イベントノードで発生する短い会話。

#### 選択肢の種類

| 種類 | 表示例 | 効果 |
|------|--------|------|
| 通常選択 | 「手を差し伸べる」 | 標準的な結果。感情値+3〜+5 |
| 沈黙 | 「……」 | 穏やかな結果。感情値+1〜+2。隠し部屋の解放条件 |
| 嘘をつく | 「大丈夫だよ（嘘）」 | 即座に大きな報酬。感情値+5〜+8。ただし後のランで呪いカード混入のリスク |

#### 嘘のメカニクス

```
嘘をつく → 短期利得（カード/金/HP回復）
              ↓
        嘘カウンター蓄積（永続）
              ↓
        閾値を超えると次ランで呪いカードが初期デッキに混入
              ↓
        特定NPCが嘘を見破り、専用の敵対イベント発生
```

#### デッキ属性によるNPC反応

- デッキの属性構成（4属性の比率）をNPCが参照する
- 菓子カードが多い → 菓子属性NPCが友好的に、樹海属性NPCが警戒
- 混成デッキ → 「あなた、どこの子かわからないわ」等の専用セリフ

### 層3：物語層

**実装優先度：★☆☆（β以降）**

複数ランをまたぐ大きな物語。

#### 記憶の欠片システム

| 要素 | 仕様 |
|------|------|
| 獲得方法 | ボス撃破、特定イベントクリア、信頼度最大到達 |
| 保存 | 永続。ラン失敗でも消えない |
| 接続 | 複数の欠片が集まると「世界の断片」として統合 |
| 解放 | 世界の断片ごとに世界の真実の一部が語られる |

#### 真のフレーバーテキスト

- 感情値が「真心」（80〜100）に到達した仲間のみ解禁
- カードの通常フレーバーテキスト（ゆめかわ）が、本当の過去を語る内容に変化する
- 例：

| 状態 | フレーバーテキスト |
|------|-----------------|
| 通常 | *「きらきらの粉が降るよ。吸い込んだら、もう関節が動かないの」* |
| 真心解禁後 | *「あの子は自分で粉を吸ったの。動けなくなれば、もう誰も傷つけなくて済むって」* |
